# Product Context

SalesPatriot scrapes 4,000+ government solicitations daily. Customers only want
relevant ones. FSC codes are the federal classification scheme used to match
solicitations to suppliers. If we know a company's FSC codes, the matching
engine can connect them to the right contracts.

User flow: a single form (name, website URL, email domain, optional doc) -> a
results page listing 4-digit FSC codes with rationale and confidence.
