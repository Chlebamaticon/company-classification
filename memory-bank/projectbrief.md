# Project Brief

MVP for SalesPatriot's "FSC Code Classifier" assignment (`SP_Task.pdf`).

Given company info (name, website URL, email domain, optional document), output the relevant 4-digit Federal Supply Classification (FSC) codes that describe what the company sells or provides.

Scope: rapid-prototype MVP, "a few hours" budget, demo-ready. Output only requirement: 4-digit FSC codes from the catalog parsed from `AV_FSCClassAssignment._151007.pdf`.
